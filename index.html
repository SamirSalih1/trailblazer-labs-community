The path

How publishing works

From a public GitHub repo to a live community listing — in four steps.

1

Ready your repo

Push your Salesforce metadata to a public GitHub repo with an open-source license.

2

Add proof

Include a README, a screenshot, and a short demo video of the asset in action.

3

Open a pull request

Add your asset to assets.js and open a PR. A maintainer reviews and merges.

4

Go live

Once merged, your asset appears in the directory for the whole community to find and install.

The framework

Why Trailblazer Labs

🧭

Low barrier to entry

Any Trailblazer with a public GitHub repo can publish. No AppExchange partner agreement, no commercial entity, no cost.

🌱

Open by default

Every asset is open source and links straight to its source. Browse the code, learn from it, and contribute back.

📈

A graduation path
