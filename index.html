Static analysis on your repository — no org access required.
How this runs: On submit, an ephemeral sandboxed runner clones your repo (read-only, no access to any Salesforce org) and runs Salesforce Code Analyzer + Graph Engine across the checks above. It re-runs automatically on every new commit via webhook. Clean assets auto-list in minutes; advisories list with a visible badge; any critical finding blocks listing and routes to the Product Security triage queue with a remediation checklist.
